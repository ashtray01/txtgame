# Текстовая игра «Башни Судьбы»

[![Играть онлайн](https://img.shields.io/badge/%F0%9F%8E%AE%20Играть%20онлайн-GitHub%20Pages-%23ffd23f?style=for-the-badge&labelColor=%230b0b0f&color=%23ffd23f)](https://ashtray01.github.io/txtgame/)

Пять башен. Пять реликвий. Одна судьба.

Давным-давно из-под земли поднялись пять башен, и в каждой хранится осколок Древней Тьмы. Собери все пять реликвий, чтобы навсегда запечатать зло — но дорога лежит через легионы нежити, демонов и тварей Пустоты. Ты — последний странник, кому по силам дойти до вершины.

## Запуск (CLI)

```
python main.py
```

## 🎮 Играть в браузере

**PLAY ONLINE:** https://ashtray01.github.io/txtgame/

Веб-версия работает без сервера: игровой Python-код исполняется в браузере через **PyScript 2024.1.1 + Pyodide** в отдельном web-worker (он обязателен, т.к. игра использует `input()`). Игровая логика — единый исходник `game/`, тот же, что и в CLI; в браузере он подгружается через `files`-конфиг (`web/pyscript.json`).

- Сохранения хранятся в `localStorage` браузера и переживают перезагрузку страницы.
- Runtime грузится с CDN `pyscript.net`; при недоступности CDN или ошибке запуска страница показывает экран `RUNTIME ERROR` с кнопкой «Перезагрузить».

### Локальный запуск веб-версии

```
python -m http.server 8000
# открыть http://localhost:8000/  (редирект на /web/)
```

В бою: `1. Атака  2. Блок  3. Зелье  4. Способность  5. Предмет`

## Классы

- **Воин** — высокое HP, средняя атака. Способность «Яростный удар» (урон x1.5)
- **Маг** — низкое HP, высокая атака. Способность «Огненный шар»
- **Разбойник** — среднее HP, высокий шанс крита. Способность «Удар в спину»

## Механики

- На вершине каждой башни ждёт **босс**.
- За башню даётся **реликвия**; собрав все пять — вы победили.
- **Золото** выпадает за бой и тратится в лавке на предметы и улучшения.
- **Отдых** требует припасы: лечит +25 HP, но может привести к засаде.
- **Заточка** (+4 ATK на бой), **Свиток силы** (25 урона), **Эликсир жизни** (+20 макс. HP).
- **Сохранение** автоматическое: в CLI пишется в `savegame.json`, в браузере — в `localStorage`; после смерти можно восстановиться.
- EXP переносится между уровнями, блок снижает урон на 70%.
